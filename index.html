Flagship · RAG

KIT Assistant

Question answering over my college's documents, with a citation for every answer.

It covers 412 institutional documents across 10 departments and answers questions about syllabus, admissions, fees, placements and policy. Each answer links to the exact page it came from.

  • Hybrid retrieval scores 61 of 63 (97%) on a benchmark I verified by hand.
  • Escalating OCR (PyPDF, Tesseract at 300 dpi, Gemini vision) recovered 19% of the corpus that plain extraction could not read.
  • Nightly incremental ingestion keyed on SHA-256 digests and ETags. A recent run handled 131 new documents against 246 unchanged in minutes.
  • Grounded answers only. When the corpus is silent, it refuses instead of guessing.

Live · MCP

Expense Tracker

A public remote MCP server that three different clients drive at once.

Claude uses it as a connector. A terminal LangGraph agent and a Google-authenticated Streamlit web app use it too. All three share one Postgres-backed state.

  • Seven typed tools validated against a 20-category taxonomy. Money is exact Decimal/NUMERIC and travels as strings, so float rounding never reaches a total.
  • Memory that survives restarts through a Postgres checkpointer, shared across both front-ends.
  • Row-level multi-tenancy, tested with two real accounts. Neither could read the other's data, and forged identity headers were overwritten at the gateway.
  • FastMCP
  • PostgreSQL (Neon)
  • LangGraph
  • OAuth 2.1
  • Streamlit

In progress · Agents

Financial Analyst Agent

An agent for 300-page annual reports, where every component is chosen by measurement.

It reads the FY25 annual reports of TCS and Infosys. I first built a ground-truth benchmark of 164 figures read from page images, then scored four PDF parsers on exact-number accuracy and row integrity.

  • Found the real cause of wrong numbers: a font that mapped digits to Greek glyphs on 247 of 336 pages. Parser selection and a glyph-repair layer fixed it.
  • Caught a flawed metric mid-benchmark. My counter under-reported one parser's errors by 320 times, and I corrected it before drawing conclusions.
  • Surfaced a silent failure: standalone and consolidated figures returned interchangeably. 31 offline pytest tests cover chat isolation and extraction.
